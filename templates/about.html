About Me

Intersting About Me

I am an 2nd MSc(Computer Science) student at The New College, Peters Road, Royapettah, Chennai, Tamil Nadu, India.


I have developed a Heart Failure Prediction System using Machine Learning techniques. The project evaluates multiple classification models to identify patient survival outcomes during the follow-up period. The best-performing model was selected and deployed using Flask as a web application.


The system allows users to input patient clinical data and receive predictions in real time. The application was successfully deployed on a cloud platform, demonstrating practical implementation of machine learning, data preprocessing, model evaluation, and web deployment.


This project reflects my strong interest in Machine Learning, Data Science, and Healthcare Analytics, and my ability to build end-to-end ML solutions.
